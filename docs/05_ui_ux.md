# UI·UX 명세 — GPT to search

## 디자인 참고 및 원칙

- ChatGPT **데스크톱 앱의 분위기**: 단순한 표면, 대화 중심, 명료한 타이포·간결한 아이콘, 밝음/어두움 테마, 과한 장식 금지.
- 공식 OpenAI 로고, 전용 에셋, 픽셀 단위 복제 금지. 사용자 연구 도구의 고유 기능/브랜딩 유지.
- PC·태블릿 우선. 모바일은 기능 접근성을 유지하되 다중 패널을 **화면 전환**으로 표현.

## 레이아웃 상태

```text
[햄버거 메뉴]  GPT to search / 프로젝트 / 세션         [통합 검색] [갱신] [알림]

기본 채팅: [                메인 채팅                ] [보조 패널: 3탭]

원문/결과물 열람:
[기존 메인 채팅(계속 입력 가능)] [중앙 작업 영역: 탭, 최대 2분할] [보조 패널]
                                  문서 또는 결과물             미니 세션
                                  또 다른 문서(선택적)          결과물 노드
                                                                세션 노드
```

- 햄버거 메뉴는 평소 숨겨 전체 화면 확보; 열 때 드로어 오버레이를 우선 적용(중앙 내용 불필요 재배치 방지).
- 중앙에 자료를 열면 메인 채팅이 **왼쪽으로 이동**한다. 닫으면 다시 넓은 중앙으로 복귀한다.
- 좌우 패널 크기 조절과 접기 가능. 콘텐츠 분할은 **최대 2개**.
- 다중 탭에서 원문·결과물을 자유롭게 열고 각 스크롤 위치를 유지한다.
- 세션마다 `workspace_states`로 탭·선택 영역·스크롤·분할·메시지 초안·우측 패널 탭을 복원한다.

## 주요 화면

### 프로젝트 홈
- 새 프로젝트, 최근 세션, 검색, 프로젝트 선택. 프로젝트별 결과물 독립성을 UI에서 명시.

### 자료조사/채팅
- 스트리밍 답변, 출처 링크, 프로젝트 목적/모델/추론 수준/외부 참조 범위 기본 슬라이더 제공.
- 고급 맥락 조절은 접힌 상태로 두고 상위 세션/다른 세션/기록 DB를 개별 조절.
- 참고한 자료·세션은 작게 표시, 선택 시 상세 위치와 내용 확인.
- 분기 버튼은 **대화·원문·결과물**에서 언제나 접근 가능; 분기 생성은 사용자만 확정.

### 원문 독해
- 원문 중앙, 채팅 좌측, 보조 패널에서 현재 원문 미니 세션 활성.
- 문단/텍스트 선택 -> 미니 세션 질문(해당 선택 범위 연결).
- 메인 채팅에서 '현재 원문으로 질문하기' 클릭 -> 수정 가능한 템플릿 + `explicit_ref` -> 사용자가 전송.
- '다 읽음' -> 메인 전송 후보 체크 목록, 키워드 선택, 기록의 부족한 내용에 관한 선택적 코멘트. 검토 건너뛰기 가능. 해제해도 아카이브 보존.
- 원문 밖 검색은 미니 세션에서 사용자 명시 요청 시에만 실행.

### 결과물 그래프/상세
- 별도 전체 결과물 그래프 화면 + 우측 간편 그래프 탭.
- Obsidian형 필터·그룹. 큰 주제와 세부 지식 노드를 계층/연관 관계로 보여 줌.
- 노드 한 번 클릭 -> 오른쪽 미리보기(현재 작업 영역 그대로). '열기' -> 중앙 결과물 상세 탭.
- 상세: 통합 본문, 출처/근거 위치, 세션 기여도 순위(%/근거), 수정 이력, 관련 세션으로 이동.
- '현재 노드로 질문하기' -> 좌측 메인 채팅에 **편집 가능한 경로 포함 프롬프트 삽입**; 전송 전까지 자동 주입·전송 없음.
- 분할된 두 자료 중 **현재 활성 자료 1개**만 질문 참조로 선택.

### 세션 그래프
- 별도 전체 그래프 + 우측 간편 그래프. 분기/관련성을 구별하고 각 노드 미리보기 후 이동.
- 세션 클릭 -> 기존 작업 공간을 보존하고 대상 세션의 상태를 복원. 이전 세션으로 돌아갈 수 있음.

### 관리/알림
- 자동 갱신 시각·미처리 수·갱신 버튼·실패/예산 한계 표시.
- 충돌 감지 알림 -> 간단한 확인 및 해결. 관리 탭 -> **동일한 1개 검토 기록**으로 두 본문 비교·충돌 구간 마킹·관련 출처를 보고 수정/승인.
- 정보 수정·통합 해제·재분류, 수정 이력 표시.

## 세션 전환/참조의 예상 상태 머신

- `chat_only` -> `content_open` when source/knowledge tab opened.
- `content_open` -> `split_2` on split action. Max two visible contents.
- `split_2` -> `content_open` on unsplit/close.
- `content_open`/`split_2` -> `chat_only` when all central content tabs closed.
- Any state -> `session_switch` saves current workspace -> loads destination workspace -> restores prior state.
- Graph preview does **not** change current workspace until '열기'.
- Click active central pane -> changes active reference **selection only**. Click '현재 자료로 질문하기' -> inserts draft and saves `explicit_ref`. Send -> server injects node content as reference.

## 접근성/반응형 기본값

- 키보드 포커스, 탭 전환, Esc 닫기, 그래프 노드의 키보드 접근 보완, 명암 대비, 스크린리더 제목/레이블.
- 모바일에서 좌측 채팅/중앙 콘텐츠/우측 보조 패널은 상호 전환하는 작업 화면으로 제공, 미작성 질문을 잃지 않음.
- 시각적 상세 색상/폭/애니메이션은 구현하며 조정. 기능 행동은 본 문서가 기준.
