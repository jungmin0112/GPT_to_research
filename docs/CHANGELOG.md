# 설계/구현 변경 이력

- 2026-11-19: 사용자 확정 결정사항을 인계 문서로 정리. 구현은 아직 시작하지 않음.

코딩 과정에서는 날짜·변경 항목·이유·영향받은 문서·테스트를 추가한다. 사용자 확정 결정에 영향을 주는 변경은 임의로 승인 처리하지 않는다.

- 2026-11-18 구현 기록. M0 Supabase 비밀번호 인증·단일 소유자·RLS·원자적 프로젝트/메인 세션 생성과 새로고침 복원 구현. 테스트 계정은 로컬 개발에서만 PGlite에 접속하며 실제 모드와 동일한 SQL을 사용한다.
- M1 첫 단면. 세션별 질문과 각 답변 시도를 분리해 재시도 이력을 보존한다. Responses 스트림·검색 제어·인용/후보 메타데이터를 연결했다. 현재 메인 세션 기록을 DB에서 재구성하며 후속 모델 상태 연결·긴 맥락 압축은 미구현이다. 검증 명령과 실제/모의 경계는 README 참조.
- 최종 검증. ESLint·TypeScript·프로덕션 빌드 성공, Vitest 3건 및 Chromium E2E 2건 통과. 첫 E2E에서 Next 개발 서버의 내부 origin과 브라우저 host 차이를 발견해 동일 출처 검사를 수정했다. 빌드가 생성 타입을 갱신하는 도중 실행한 독립 typecheck는 파일 경합으로 실패했고 순차 재실행은 통과했다. 로컬 실제 Auth/REST/DB 시나리오와 별도 계정 차단도 통과했다. 전체 Supabase CLI 스택은 디스크 제약으로 검증을 개별 서비스로 진행했다.
- 2026-11-19. Windows 개인용 메인 세션의 실제 추론을 공식 Sign in with ChatGPT 플랜 경로로 전환했다. Supabase 데이터 모델·저장 RPC는 유지한다. 웹 검색 기본값은 꺼짐이고, 문서상 금지된 max_output_tokens·max_tool_calls를 제외했다. Windows 적용 및 실계정 인수 절차는 docs/10_chatgpt_plan.md에 있다.
- 2026-11-19. 메인 세션의 스트리밍·저장 답변에 공통 GFM 렌더러를 적용했다. 표 영역 가로 스크롤과 HTTP(S) 본문·출처 링크의 새 탭 열기를 지원한다. Playwright로 원문 및 PDF 쿼리 보존, 390px 화면에서 스트리밍·완료·복원을 검증했다.
- 2026-11-19. 프로젝트 자료함에 URL·PDF·붙여넣은 텍스트를 등록하고 열 수 있다. 기존/신규 검색 근거는 완료 답변에서 자료함으로 연결한다. M1에서는 프로젝트별 원본 및 추출 상태를 project_materials에 함께 보관하며 답변별 근거는 원래 chat_replies에 유지한다. 설치 순서와 검증 범위는 docs/11_project_materials.md에 기록했다.

## 2026-11-19 · 모듈 경계와 세션 작업 공간

프로젝트·세션·AI·자료·그래프·작업 공간의 공개 인터페이스로 M0/M1을 이전했다. 세션별 문서 탭·2분할·스크롤 복원과 명시적 자료 참조를 추가했다. 기존 자료 보관 SQL 이후 202611190003_source_turn.sql을 적용한다. Windows 적용 절차는 README, 모듈 소유권은 docs/architecture.md에 기록했다.

## 2026-11-19 · 프로젝트 자료함

자료 목록을 프로젝트 메뉴의 자료함으로 이동하고 검색·필터, 입력창에서의 직접 등록과 재사용, 메시지에서 첨부 열기를 연결했다. 계정 관리와 모델 선택 위치를 분리했다. 문서·대화·보조 패널은 각각 스크롤한다. DB 오류 코드는 원문 메시지와 요청 인수 없이 전달한다. 적용 순서는 docs/12_library_workspace.md에 기록했다.

## M2·M3 독해 및 증분 통합

프로젝트 자료에 독립 미니 세션을 연결하고 선택한 완료 문답을 원본 식별자와 함께 메인 세션으로 복사한다. 심화 분기의 부모와 자료 관계를 DB에 저장한다. 증분 분석은 원본 이벤트를 선점하고 같은 트랜잭션에서 결과 및 변경 이력을 기록한다. 충돌 검토에는 원문 인용을 남긴다.

## 통합 MVP

원문별 독해 정리 및 선택 전달, 분기와 출처별 컨텍스트 설정, 증분·수동 갱신, 프로젝트별 결과물과 버전 검토, 두 그래프와 검색·내보내기를 연결했다. 선택된 플랜 계정에서 작업별 모델과 추론 수준을 설정할 수 있다. SQL 적용과 개인용 HTTPS 호스트 운영은 docs/13_integrated_mvp.md에 기록했다.

- Windows 개인 호스트용 루프백 프로덕션 실행, 사용자 로그인 작업, Cloudflare Access 소유자 검사와 PC 부하 측정 도구를 추가했다. PC 모드에서는 기존 로컬 작업자가 자동 갱신을 담당한다.
