## 개발 기본안 — 필요하면 조정하고 문서화

- Next.js App Router, Supabase Auth/PostgreSQL/Storage/Cron/Edge Functions, Vercel, shadcn/ui, `@xyflow/react`, Vitest/Playwright.
- 단일 사용자 보호: 가입 제한/허용 계정 ID와 RLS, 비공개 버킷.
- 모델 ID는 환경 변수/설정으로 제공. 계정 지원 여부는 실제 연동으로 확인.
- 자동 갱신 예정 시간 확인은 1분 간격, 최소 자동 분석 간격은 처음 3분으로 제안하되 실제 비용/반응성 테스트 후 조절.
- 검색/원문 자동 보관은 메타데이터를 폭넓게 수집하고 전문 확보는 접근·이용 조건과 용량 제한에 따름.
- 결과물 점유율은 구조화된 근거/기여 항목을 정규화; 산정 불가 시 수치 대신 상태 표시.
- 2D 그래프의 레이아웃·색·물리 상수, UI의 픽셀 수·반응형 브레이크포인트는 구현 중 검증.

## 해결 필요 시 우선 확인할 항목(제품 결정이 아닌 환경 설정)

- 사용자의 Supabase 프로젝트 URL/사용자 ID, Vercel 프로젝트 연결과 OpenAI API 키 등 비밀값을 **코드에 기록하지 않고** 환경 변수로 적용.
- 실제 사용 모델·웹 검색·reasoning 지원 조합, API 요금 한도.
- 원문 추출이 가능한 사이트 범위 및 문서 파일 최대 크기.
