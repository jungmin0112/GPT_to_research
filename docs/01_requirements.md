# 기능 요구사항 — GPT to search v1.0 (확정 설계)

## 제품 원칙

- **채팅하는 연구 도구**: 사용자가 원문을 읽고 질문하는 주체다. AI는 조사를 돕고 정보를 조직한다.
- **연구의 자유도**: 단일 직선 대화가 아니라 언제든 심화 분기, 다층 분기, 이전 세션 복귀가 가능하다.
- **기록과 모델 컨텍스트의 분리**: 중앙 DB는 과거 전체 기록을 관리하지만, GPT에는 요청에 필요한 정보만 전송한다.
- **원본 보존/가공 결과 구분**: 원문·대화의 기록과 AI 요약·최종 지식은 서로 다른 개체다.
- **프로젝트별 독립**: 세션/결과물 그래프가 프로젝트별로 존재하며, 다른 프로젝트는 참조만 가능하다.

## 기능 요구사항 및 완료 조건

### F01 프로젝트와 탐구 세션
- 개인 계정 로그인 후 프로젝트 생성/이름 변경/전환/검색 가능.
- 프로젝트당 메인 세션과 여러 심화 세션 생성. 분기는 현재 세션, 특정 메시지, 원문 위치, 결과물 노드 등에서 가능.
- 깊이 상한을 UI에서 임의로 정하지 않는다. 부모 세션, 분기 출발점과 생성 시 설정을 저장.
- 새 심화 주제는 AI가 추천할 수 있으나 **자동으로 세션을 만들지 않는다.**
- 세션별 독립 대화·모델 선택·맥락 설정·작업 공간 상태 유지; 모든 층위에 직접 이동/복귀.

### F02 일반 GPT 채팅 및 검색
- ChatGPT형 스트리밍 대화. 사용자 메시지 편집은 필수가 아니지만 답변 재시도·오류 표시 필요.
- 사용자가 직접 웹 검색 요청 또는 검색 제한 가능. 일반 메인·심화 세션은 AI가 필요 시 자율 검색 가능.
- 검색/인용 출처를 클릭 가능하게 표시. AI가 외부 자료를 사용했는지와 내부 기록을 참조했는지 구별.
- 모델·추론 수준은 작업별 기본값 + 사용자 오버라이드. 미지원 모델/설정은 유효성 검사하여 안전한 대안 제시.

### F03 자료 자동 수집과 보관
- URL, PDF, 텍스트 입력 지원. 검색 결과 중 관련성 높은 자료를 **폭넓게 자동 보관**.
- 검색 결과 후보와 인용 자료를 구분하고, 메타데이터 보존. 허용 가능한 경우 원문 텍스트/파일 추출.
- 동일 링크·본문 해시 중복 방지, 수집 실패·전문 미확보·접근 제한 상태 명시.
- 원문을 가져오는 작업은 대상 사이트 정책과 저작권 및 접근 제약 준수. 무단 전문 복제·접근 차단 우회 금지.

### F04 원문 읽기/미니 세션
- 중앙 탭에서 원문 열람, 원문의 문단/선택 범위를 지정해 질문.
- 원문마다 **독립 미니 세션**; 기존 채팅과 혼합하지 않는다. 빠른 모델·낮은 추론 기본값, 변경 가능.
- 미니 세션은 원문 중심. 외부 검색은 사용자의 명시 요청에서만 허용.
- '다 읽음' 시 해당 원문에 연결된 질문·답변을 **일괄 분석**하여 정리. 원본은 모두 저장.
- 완료 패널: AI 선별 후보 항목(기본 체크, 선택/해제 가능), 관심 키워드, 기록상 부족한 내용을 묻는 선택적 짧은 질문; 사용자는 건너뛰기 가능.
- 해제는 **메인 세션으로의 전달만 제외**하며 원본/정리 기록은 아카이브에 남는다. 완료 후 필요시 다시 읽을 수 있다.

### F05 컨텍스트/세션 기억
- 현재 대화는 이어가되, 외부 기록 참조 범위를 세션 생성 시 설정하고 진행 중에도 변경.
- 기본 슬라이더(독립·최소·관련·넓게·최대) + 숨겨진 고급 출처별 슬라이더(상위 세션/다른 세션/조사 기록).
- 범위를 낮춰도 **기존 대화와 이미 전달된 외부 정보는 지우지 않는다**. 앞으로 추가로 가져올 정보에만 적용한다.
- 사용된 내부·외부 참조는 간단히 표시하고 상세 확장 가능.
- 사용자 설정의 범위를 넘는 다른 세션 데이터 주입 금지. 현재 선택한 자료의 명시적인 '질문하기' 동작은 별도 참조 허용.

### F06 중앙 조직화/자동 갱신
- 원본은 즉시 저장. AI 요약·관계 분석·지식 통합은 별도 비동기 작업으로 관리.
- **기본 10분** 갱신; 대화량·세션 생성/종료 등 가중치로 예정 시각 앞당김. 활동하지 않았다면 AI를 호출하지 않음.
- '지금 갱신' 버튼 제공. 중앙 스케줄러 + 세션별 우선순위(C안); 증분 갱신, 중복 실행 방지, 재시도/실패 표시.

### F07 세션 그래프
- Obsidian형 2D 노드/연결선. 프로젝트 세션을 기본 단위로 분기·의미적 관련성 표시.
- 필터(표시 대상)·그룹(시각적 분류), 전체 그래프와 작은 보조 패널 접근.
- 그래프 노드 클릭 시 **미리보기**, '열기'를 누르면 이동. 세션 전환 시 해당 작업 공간 복원.

### F08 결과물 지식 그래프
- 조사에서 정리·확정된 내용만 AI가 자동으로 결과물에 등록. 가설/미해결 질문은 조사 기록에 보존하되 결과물에 자동 등록하지 않는다.
- 큰 주제와 세부 정보가 계층 및 의미 관계로 연결된 지식 노드. 노드 선택 시 본문·출처·변경 이력·관련 세션 기여도 순위.
- 같은 프로젝트의 중복/유사 기록은 하나의 통합 본문으로 AI가 재구성. 원문과 수정 이력 보존.
- 다른 프로젝트 결과물은 별도 독립 관리(B안); 관계/참조 링크만 제공하고 자동 합병/동기화하지 않는다.

### F09 세션 기여도('점유율')
- 정보 노드마다 각 세션의 **실질적인 새로운 정보/확장/근거 보강**에 따른 상대적 기여도를 추정.
- 동일 내용의 반복은 과대평가하지 않음. 기여도 근거 기록 ID를 보관하고 합계로 정규화해 % 표시.
- 측정된 객관적 사실의 정확도나 AI 확신도를 뜻하지 않는다. 근거 부족 시 임의의 퍼센트를 만들지 않고 산정 불가 표시.
- 순위에서 해당 세션으로 직접 이동해 탐구 재개.

### F10 정보 충돌 검토
- 새 자료와 기존 결과물의 모순 검출 시 충돌 부분 자동 덮어쓰기 금지.
- 중앙 업데이트 후 알림; 알림에서 간편 처리, 관리/결과물 탭에서 상세 처리. **한 번 생성한 공통 검토 기록**을 두 화면에서 재사용.
- 기존·신규 본문 병렬 보기, 충돌한 구간 마킹, 출처 표시, 사용자 결정·수정 후 이력 저장.
- 별개의 정상 정보는 충돌 부분의 보류 때문에 업데이트가 막히지 않음.

### F11 작업 공간 UX
- ChatGPT 데스크톱 앱의 간결한 UI 감각. 햄버거 메뉴는 접기/펼치기. 단, 공식 로고 복제 금지.
- 기본 중앙 메인 채팅. 원문·결과물 열면 기존 채팅은 **왼쪽으로 이동**하고 계속 대화 가능, 콘텐츠는 중앙.
- 오른쪽 보조 패널: 미니 세션 / 결과물 노드 / 세션 노드 3탭.
- 중앙 다중 탭 지원, 화면 분할 **최대 2개**. 분할 시 현재 활성 자료 **하나**만 '현재 자료로 질문하기'의 참조 대상.
- 질문 버튼을 누르면 사용자 수정 가능한 프롬프트를 입력창에 작성; 자동 전송하지 않음. 전송 시 정확한 source/node ID를 별도 전달. 탭을 열었다는 이유만으로 본문을 매번 자동 주입하지 않음.
- 세션별 열린 탭·스크롤·분할 상태·메시지 초안 등 복원.
- PC·태블릿 우선, 모바일은 전환형 화면으로 기본 기능 접근.

### F12 통합 검색/관리/내보내기
- 프로젝트·세션·원문·결과물 통합 검색 및 종류별 필터.
- 관리 탭에서 정보 수정/재분류/통합 해제, 충돌 처리, 처리 상태 및 사용량 확인.
- 결과물과 출처를 Markdown/PDF로 내보내기.

## 제외 또는 고도화 대상 (MVP에서 기능 제거를 뜻하지 않음)

- 복잡한 문서 형식/접근 제한 사이트의 원문 완전 지원
- 자동 분석의 정교한 최적화 및 고급 그래프 물리 배치
- 세션별 점유율 알고리즘의 완전한 학술적 정확도 보장
- 조직 협업·다중 사용자·대외 공개용 브랜드 운영
- 보고서 자동 집필·템플릿 에디터(사용자가 선택한 외부 활용 B안은 내보내기임)
