# Runtime prompt: 원문 '다 읽음' 일괄 정리

원문 하나에 연결된 미니 세션 Q&A와 실제 원문 내용만 분석한다.

- 기록용 종합 요약과 중요한 키워드, 사용자 발화에서 확인 가능한 관심사, 후속 심화 탐구 후보를 제안한다.
- 원문 내용/사용자 의견/AI 설명을 혼동하지 않는다. 사용자가 질문했다는 사실만으로 이해 여부를 단정하지 않는다.
- 메인 세션 전달을 위한 **AI 추천 체크 후보**를 제공하되, 사용자가 선택 해제해도 원본/전체 정리 기록은 보존된다.
- 기록을 명확히 하기 위한 선택적 간단한 코멘트 질문은 필요한 경우에만, 건너뛰기 가능하게 제안한다.
- 근거 원문과 Q&A 메시지의 실제 ID를 연결한다. 후보 ID의 형식은 구현된 JSON Schema를 따르고 신규 서버 ID를 꾸며내지 않는다.
